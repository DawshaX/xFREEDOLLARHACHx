# NOVA — منصة الأمان

مستودع العمل الجديد لمشروع NOVA، منقولًا من الأرشيف الموجود في `DawshaX/nova` إلى `DawshaX/xFREEDOLLARHACHx`.

> **الحالة:** أساس منقول ومنقّح + لوحة تحكم آمنة للقراءة والتحقق المحلي. **تشغيل NOVA القديم معزول، وفحص الأهداف الخارجية غير مفعّل.** هذه ليست منصة مكتملة ولا يوجد تكامل رسمي مع HackerOne أو Google.

## ما الذي أُنجز؟

- نقل 480 ملفًا مصدريًا من الأرشيف، مع استبعاد المخرجات المبنية وخرائط المصدر والسجلات والأرشيف نفسه.
- إزالة قيم أسرار وعناوين تشغيل خاصة من المصدر المنقول، وإلغاء بيانات إشعارات مُضمّنة.
- عزل نقطة تشغيل الـAPI القديمة، وتوجيه أوامر التشغيل الافتراضية إلى لوحة التحكم الآمنة.
- لوحة عربية توضح القدرات الحقيقية، وتقدم تحققًا محليًا من سجل النطاق ومكتبة معرفية أولية.
- اختبارات للنطاق والـAPI، وفحص أنماط أسرار قبل الدفع، وCI.
- وثائق حالة ومراجعة وخطة وسجل جلسة منقّح للاستكمال من محادثة أخرى.

## التشغيل الآمن

لا يحتاج إلى تثبيت حزم أو قاعدة بيانات أو مفاتيح:

```bash
node platform/server.mjs
# أو
npm start
```

افتح `http://localhost:3000`. المنصة تستمع على `0.0.0.0` لتعمل في بيئات المعاينة.

## النسخة المنشورة

لوحة التحكم الثابتة الآمنة تُنشر عبر GitHub Pages على:

`https://dawshax.github.io/xFREEDOLLARHACHx/`

هذه نسخة ثابتة فقط: المكتبة والتحقق المحلي يعملان دون خادم، لكنها لا تشغّل API أو أدوات فحص. أول نشر قد يتأخر حتى يكتمل GitHub Actions.

```bash
npm test
npm run check
```

> **تنبيه اعتماديات:** Dependabot رصد 88 تنبيهًا في حزم المشروع القديم، منها 12 حرجة و42 عالية. لوحة التحكم الآمنة لا تستخدم هذه الحزم، لكن لا تُشغّل الأجزاء القديمة قبل تحديثها ومراجعتها. التفاصيل في [المراجعة الأمنية](docs/SECURITY_REVIEW.md).

## ما الذي لا يفعله هذا الإصدار؟

- لا يفحص أي موقع أو نطاق خارجي.
- لا يشغّل أوامر على الخادم أو على جهاز Kali.
- لا يتصل بـHackerOne أو Google أو أي مزود ذكاء اصطناعي.
- لا يدّعي اكتشاف ثغرات، ولا يعرض نتائج محاكاة على أنها حقيقية.
- لا يرفع محادثات خام أو توكنات أو بيانات اعتماد إلى Git.

## لماذا عُزل التشغيل القديم؟

المراجعة وجدت مسارات تنفيذ أوامر وWebSocket وتحكم بالملفات دون مصادقة وتفويض واضحين، وأسرارًا مضمنة، ووحدات تعيد نتائج محاكاة. تشغيلها كما هي على شبكة عامة قد يعرض الخادم والأجهزة المتصلة للخطر. التفاصيل في [المراجعة الأمنية](docs/SECURITY_REVIEW.md).

## خريطة المستودع

```text
platform/                 لوحة التحكم الآمنة والنطاق والمكتبة والاختبارات
artifacts/api-server/     كود API الموروث؛ نقطة التشغيل معزولة
artifacts/kali-panel/     واجهة React الموروثة؛ ليست مفعلة افتراضيًا
lib/                      مكتبات وقاعدة بيانات موروثة
docs/                     الحالة، المراجعة، المعمارية، الخطة، وسجل الجلسة
scripts/check-migration.mjs فحص النقل وأنماط الأسرار
migration-manifest.json   مصدر النقل وما استُبعد
```

## مبادئ العمل

- التفويض والنطاق قبل أي اختبار؛ وجود برنامج مكافآت ثغرات لا يعني إذنًا شاملًا.
- لا ضمان لاكتشاف «كل الثغرات». كل نتيجة تحتاج دليلًا قابلًا لإعادة التحقق ومراجعة بشرية.
- الأدوات تعمل بأقل صلاحية، وبحدود موارد، وبسجل تدقيق.
- لا أسرار في الكود أو الواجهة أو سجل Git. الأسرار التي تعرضت يجب إلغاؤها/تدويرها، وليس حذفها من الملف فقط.
- الكود والمخرجات الموروثة لا تُعتبر آمنة لمجرد نقلها إلى مستودع جديد.
