# القاعدة الواحدة: جيت-هَب نفسه هو السيرفر

> السؤال كان: «عايزين موقع أو مكان واحد يغنينا عن كل ده وأحسن منهم كلهم ومجاني».
> الإجابة بعد ما قِست النهارده (2026-11-02): **مفيش مكان واحد مجاني بيدي كل حاجة** —
> بس فيه مكان واحد مجاني بidi **أهم حاجتين** وبيسيب التالتة تتحل بملف: **جيت-هَب**.
> اللي بعده في الورقة دي مفيش منه بيعدي اختبارين اتنين مع بعض: root + نت كامل + بلا كارت
> + بلا نوم + للأبد.

## ليه جيت-هَب هو «المكان الواحد» عملياً

| الحاجة | جيت-هَب بيريحها إزاي | أي مضيف مجاني تاني |
|---|---|---|
| جهاز تشغيل حقيقي | كل job = أوبونتو 4 أنوية / **16 جيجا** / `sudo` كامل | 256–512 ميجا، أو 2 جيجا مشارَكة |
| أدوات هجوم حقيقية | `apt install nmap` + سكربتات ProjectDiscovery بتنزّل في `/usr/local/bin` | ممنوعة في شروط الاستخدام (GratisVPS) أو مفيش root |
| الدقايق | **غير محدودة** على ريبو عام | Render 750 ساعة/شهر ثم فاتورة |
| النوم | مفيش نوم — مفيش عملية دايم بس، وده محلول (تحت) | Render/SnapDeploy 15 دقيقة، Koyeb ساعة |
| كارت/هوية | مفيش خالص | Oracle/Qoddy/GCP/Azure-عام بيدوا كارت للتوثيق |
| نت حقيقي | طبعاً | طبعاً — ما عدا صندوق التطوير بتاعي (مفيش خروج خالص) |
| الداتا بيز | commits جوه الريبو + Pages بيخدمها كـJSON | Silly/GratisVPS فيه DB مجاني |
| العنوان العام | **Pages** (`…/xFREEDOLLARHACHx/`) بـHTTPS، ومفيش إعدادات | أي PaaS |
| التخزين/النسخ | Releases + Artifacts (30 يوم) + الريبو نفسه | مايلوش |

**واللي مالوش:** مافيش منفذ عام يستقبل اتصال من برّه، وjob بيموت بعد 6 ساعات، وcron
أقرب حاجة لـ«كل 15 دقيقة» (مش ثانية). الدولتين دول بالظبط اللي بيخليك محتاج
**صندوق بريد صغير** (Waifly دلوقتي، SillyDev بعدين) للرسايل اللحظية والـWebSocket.
لو الـhub واقع؟ الشغل التقني بيمشي عادي — الطابور جوه الريبو.

## إزاي الشغلة متوصّلة (مفيش سحر، فيه ملف)

```
      تحرّر من واجهة جيت-هَب
state/nova-queue.json  ──push──▶  workflow nova-runner.yml
                                          │ 1) يبني المحرك الحقيقي (api-server)
                                          │ 2) ينصّب nmap/nuclei/httpx/subfinder/katana/dnsx
                                          │ 3) يقدّم المحرك على 127.0.0.1 ويسأله من خلال /api/ops/*
                                          ▼
                     reports → artifacts/kali-panel/public/nova-runs/<id>.md|json|index.json
                                          │ 4) commit [skip ci] → Pages ينشرهم
                                          ▼
   https://dawshax.github.io/xFREEDOLLARHACHx/nova-runs/index.json
```

نقطة التصميم المهمة: الـrunner **ما بيعيدش تنفيذ أي منطق**. كل بعثة بتدخل من
`/api/ops/jobs` — نفس بوابة التصريح (`assertAuthorized`)، نفس الـrate limit لكل
برنامج، نفس رفض العمق النشط من غير إذن مكتوب، ونفس كاتب الأدلة. يعني الطابور ده
مش «باب خلفي»: هو عميل عادي شغال على جهاز فيه الأدوات.

### شكل بند الطابور

```json
{
  "id": "recon-acme",
  "title": "استطلاع أولي على acme.com",
  "objective": "اطلع السجلات والشهادات والحقوق قبل أي حاجة",
  "target": "acme.com",
  "depth": "passive",
  "tools": false,
  "status": "queued"
}
```

- `depth`: `passive` (آمن من IP جيت-هَب) · `standard` / `deep` (هيترفضوا لحد ما
  تفعّل `NOVA_RUNNER_ALLOW_ACTIVE=1`).
- `tools: true` لوحده ماتكفيش — بيتفعّل بس لو العمق النشط مسموح، لأن `nuclei` و`httpx`
  بيلمسوا الهدف فعلاً.
- `programId` اختياري: لو عندك برنامج مصرّح به في الـhub اربطه بيه، غير كده الـrunner
  بيعمل `discover` بنفسه فالتصريح بيتسجّل في نفس المكان اللي بيتنفّذ فيه الشغل.
- الحالة بترجع `done` / `failed` / `skipped` مع `jobId` ورابط التقرير جوه نفس الملف.

| المرشح ليرتاح على كل ده | الحكم | المصدر |
|---|---|---|
| **Qoddy** (qoddi.com) — 512 MB + DB مجاني + بلا نوم | ❌ **كارت ائتمان للتوثيق حتى على الخطة المجانية** (مسجّل 2023-01-19 و2025-09-17 و**2026-08-28** — نفس الشرط ما اتغيّرش) | agentdeals.dev (2026-09-24) |
| **Sealos** — DevBox/K8s بـDocker كامل | ❌ **مفيش خطة مجانية في 2026**: تجربة 7 أيام ثم $7–$2030/شهر | sealos.io + topeaglerservers (2026-10-21) |
| **Hugging Face Spaces** — 2 نواة / 16 جيجا بـDocker وroot | ❌ من 2026 **إنشاء Space بـDocker/Gradio محتاج خطة PRO ($9)**؛ الفاضي بس Static + جوج ZeroGPU Gradio. وكمان بيينام بعد 48 ساعة سكون، و**الخروج متقفل على بورتات 80/443/8080 بس** → أي مسح بورتات مستحيل حتى لو فتحناها | hub docs عبر toolfreebie (2026-09-02) + fastero (2026-09-16) |
| **Cloudflare Containers** — كونتينر على الحافة | ❌ محتاج **Workers Paid $5/شهر**؛ والسقف المجاني 375 دقيقة vCPU/شهر = مايشيلش عملية 24/7 | cloudflare.com/plans + flarecalc (2026-03) + northflank (2026-02-25) |
| **Codespaces** (120 ساعة نواة/شهر) | ⚠️ root حقيقي ومينفعش يستقبل؛ 60 ساعة على 2 نواة = **شهر مش 24/7**، وIP بتاع جيت-هَب برضه | GitHub docs |
| **Oracle Always Free** | ✅ أقوى «حساب واحد» حقيقي (Arm، ديسك 200 جيجا، root، بلا نوم) بس **بيطلب كارت** وبيسحب الأمثلة الخاملة — فضل الخيار الأول لو تقدر تفتح حساب | صفحة Oracle + gratisvps (2026-10-20) |

**الخلاصة التنفيذية:** المكان الواحد = **جيت-هَب (عقل + عضلات + نشر)**، و**صندوق بريد
مجاني صغير** للّحظية. أي حاجة تانية «مكان واحد» بترجعلك بواحد من دول: كارت، أو نوم،
أو 256 ميجا، أو ممنوع تمسح.

## لو عايز تلغي الصندوق الصغير خالص

كل حاجة في الريبو شغالة من غير hub، ماعدا حاجتين: `POST` لحظي من المتصفح للأدوات،
وWebSocket للأسطول. لو دول مالهمش حاجة عندك دلوقتي:

1. الطابور (الملف ده) بياخد أوامرك كل 15 دقيقة من غير أي سيرفر.
2. `workflow_dispatch` على `fleet-nodes.yml` = موجة نودات (لحد 19) وقت ما تحب.
3. `free-host-survey.yml` بيقيس المضيفين وبيكتب `state/free-hosts.md`.
4. `deploy/oracle-setup.sh` + `docs/FREE-HOSTS-2026.md` = لو يوم ما لقيت كارت/إيميل
   جامعي، NOVA بتتحول لـ24/7 كامل في 10 دقايق من غير ما تغيّر سطر في الكود.
