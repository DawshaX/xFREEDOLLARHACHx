# النشر والتشغيل

## GitHub Pages — لوحة ثابتة آمنة

المسار `.github/workflows/pages.yml` ينشر محتوى `platform/public` فقط إلى GitHub Pages عند تغيير اللوحة أو المسار نفسه على `main`.

الرابط المتوقع:

`https://dawshax.github.io/xFREEDOLLARHACHx/`

اللوحة تعمل بدون خادم: المكتبة مضمنة، والتحقق من النطاق يعمل محليًا في المتصفح. لا يوجد فحص أهداف أو تشغيل أدوات.

## التشغيل المحلي الكامل للوحة الآمنة

```bash
node platform/server.mjs
```

يوفر الخادم واجهة وAPI للقراءة والتحقق المحلي فقط. لا يحتاج إلى أسرار أو قاعدة بيانات.

## ما لا يُنشر

- لا يُنشر `artifacts/api-server` القديم.
- لا تُنشر قاعدة بيانات أو مفاتيح أو سجلات.
- لا تُشغّل مهام فحص أو أدوات Kali في CI أو Pages.

## قبل أي نشر مستقبلي لمشغّل أدوات

يجب استكمال شروط `docs/SECURITY_REVIEW.md`: مصادقة، تفويض، نطاق ملزَم، عزل مشغّل، حدود موارد، سجل تدقيق، ومراجعة بشرية. لا تستخدم GitHub Pages لتشغيل خادم أو أدوات؛ فهو استضافة ثابتة فقط.
