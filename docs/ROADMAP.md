# خطة البناء المرحلية

## المرحلة 0 — النقل والعزل (منجزة في هذا الإصدار)

- [x] فحص الأرشيف ومساراته قبل الفك.
- [x] نقل المصدر إلى المستودع الجديد دون الأرشيف والمخرجات المبنية.
- [x] إزالة أنماط الأسرار وعناوين التشغيل الخاصة المعروفة.
- [x] عزل تشغيل API القديم.
- [x] لوحة حالة آمنة ومكتبة أولية وتحقق نطاق محلي.
- [x] اختبارات وفحص نقل وCI.

## المرحلة 1 — الهوية والتفويض

- [ ] اختيار نموذج مستخدم/فريق وأدوار.
- [ ] مصادقة آمنة وجلسات/رموز قصيرة العمر.
- [ ] تفويض على الخادم لكل مورد وإجراء.
- [ ] سجل تدقيق وسياسة احتفاظ بالبيانات.
- [ ] اختبارات رفض الوصول المتقاطع بين المستخدمين.

## المرحلة 2 — النطاق والتصريح

- [ ] سجل برامج وأصول ومراجع تفويض وانتهاء صلاحية.
- [ ] مطابقة نطاق وwildcard وفق سياسة كل برنامج.
- [ ] منع العناوين الخاصة وإعادة التوجيه الخارجة عن النطاق.
- [ ] استثناءات أنواع الاختبار وحدود المعدل.
- [ ] موافقة بشرية لكل مهمة نشطة.

## المرحلة 3 — المشغّل المعزول

- [ ] حاوية/عملية منفصلة بأقل صلاحية.
- [ ] قائمة أدوات محددة بإصدارات مثبتة وتراخيص واضحة.
- [ ] وسائط منفصلة عن shell، حدود وقت/ذاكرة/شبكة.
- [ ] إلغاء مهمة وإيقاف طارئ.
- [ ] التقاط دليل خام وربطه بالمهمة والنطاق.

## المرحلة 4 — المعرفة والذكاء

- [ ] مصادر CVE/CWE/KEV بمزامنة مجدولة ووقت واضح.
- [ ] فهرسة كتب ومراجع مصرح بها فقط.
- [ ] تصنيف النتائج: مؤكد، محتمل، محاكاة.
- [ ] مساعد يشرح الدليل ويقترح تحققًا آمنًا، دون تنفيذ تلقائي غير مقيد.

## المرحلة 5 — التقارير والتكامل

- [ ] قوالب تقارير قابلة للمراجعة.
- [ ] مراجعة بشرية قبل الإرسال.
- [ ] تكامل GitHub للصلاحيات وسجل التقدم.
- [ ] تكامل برنامج مكافآت فقط عبر واجهة وشروط متاحة ومصرح بها.

## ليس هدفًا واقعيًا

«استخراج كل الثغرات في العالم تلقائيًا وبشكل كامل» ليس ضمانًا يمكن تقديمه. الهدف القابل للقياس: تغطية واضحة، أدلة قابلة لإعادة الإنتاج، وتقليل النتائج الكاذبة، مع احترام النطاق والقانون.
