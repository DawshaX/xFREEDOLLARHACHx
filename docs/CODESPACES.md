# نوفا على GitHub + Codespaces — جيت هوب هو الأساس، والسيرفر مجرد عدّاء

الريبو فيه `.devcontainer/devcontainer.json` شغال ومتقاس عليه (مش مكتوب عشان
الشكل): الكودسبيس بتبني المحرك **واللوحة**، بتنزّل nuclei/httpx/katana من
المرآة، بتولّد توكن التنفيذ في `.env.local`، وبترفع البورت 8080 public لوحده
عشان يفلت من حيطة الـ401 بتاعة جيت-هَب (اتقاست 2026-11-05، والتصحيح معمول في
`postStartCommand` يدويًا قبلها).

## تشغيله (من غير أي حساب جديد ولا كارت)

1. على صفحة الريبو: **Code → Codespaces → Create codespace on main**
2. استنى البناء يخلص (`scripts/nova-machine-setup.sh`)
3. افتح صفحة الأسطول على Pages — `https://dawshax.github.io/xFREEDOLLARHACHx/` → «محطة نوفا»
4. الصق **رابط البورت العام** (شكله `https://<name>-8080.app.github.dev`) + التوكن اللي في `.env.local`

كده الأسطول بقى فيه جهاز جيت-هَب (4 أنوية / 16GB) جنب حاوية Waifly (0.4 CPU /
460MB) — وأي مهمة `tools.*` من اللوحة ممكن تتنفّذ على الغني. الكوتا المجانية
~120 core-hour في الشهر → جهاز 2-core بيصحى ساعات يوميًا تكفي.

## «مش عايزين نعتمد على السيرفر لوحده» — دي أصلًا حقيقة المنظومة

| الطبقة | تعيش فين | لو Waifly وقعتًا |
|---|---|---|
| الواجهة العامة | GitHub Pages — `dawshax.github.io/xFREEDOLLARHACHx` | شغالة، بلا سيرفر |
| إنتاج البيانات (corpus/tools/advisories) | CI workflows على main كل 15–30 د | شغالة، بلا سيرفر |
| الطابور + الأدلة | ملفات `state/` جوه الريبو نفسه | شغالة، بلا سيرفر |
| تنفيذ المهمات الثقيلة | `nova-runner.yml` (أجهزة جيت-هَب 16GB) | شغالة، بلا سيرفر |
| الدردشة والتنفيذ اللحظي | Waifly + أي عقدة فعّالة | تقع لوحدها وترجع لوحدها (supervisor + auto-rollback) |

يعني «الدنيا» مش على سيرفر واحد: الـstate والإنتاج والتنفيذ الثقيل في جيت هوب،
وWaifly هو بس العدّاء اللحظي. ولأن الـstate في الريبو، أي عدّاء جديد بيكمّل من
آخر ما وصلنا — مش من الصفر. دي «ما بيفصلش» الحقيقية.

**الحدود الواقعية** (عشان مافيش وهم): الكودسبيس بتنام بعد ~30 دقيقة idle،
ورانر الـActions بيموت بعد 6 ساعات، والـActions العامة ببلاش من غير سقف دقايق.
جيت-هَب نفسه مش «سيرفر 24/7» — هو مصنع وعدّاءات عند الطلب، وده بالظبط اللي
الهيكل مبني عليه.
