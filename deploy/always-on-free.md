> ده المسار الوحيد اللي لقيناه بيحقق التلاتة مع بعض:
> **مجاني للأبد** + **مفيش بطاقة بنكية** + **ماينامش ولا بيقفل** (مفيش sleep، مفيش حد ساعات شهري).

## الحزمة جاهزة — مش محتاج تبني حاجة

الريبو بيبني **حزمة محمولة** أوتوماتيك على سيرفرات GitHub ويحطها في Releases:

👉 **Releases → `nova-portable` → `nova-24-7.zip`** (حوالي 2.5 ميجا)

جوّاها:
```
server.mjs        السيرفر كله في ملف واحد (مدمج بـesbuild)
public/           الواجهة جاهزة
state/            الذاكرة طويلة الأمد وملف العقل السحابي
start.sh          التشغيل
start-tunnel.sh   تشغيل + رابط HTTPS مجاني
README.txt
```

**مفيش `npm install`. مفيش build. مفيش pnpm.** Node 20+ بس.
(اتأكدنا: الحزمة بتشتغل من مجلد فاضي، 15/15 فحص، والذاكرة بتتكتب جوه `state/`.)

## الخطوات (5 دقايق، مرة واحدة)

### 1) نزّل الحزمة
من **Releases** في المستودع → `nova-portable` → `nova-24-7.zip` → فك الضغط عندك.

### 2) اعمل حساب
<https://sillydev.co.uk/panel/auth/register> — **مفيش كارت ولا بيانات دفع**.

### 3) اعمل سيرفر
من اللوحة: **Create Server** →
- Runtime: **Node.js** (20 أو 22)
- RAM: 256 MB (الافتراضي)
- بعد الإنشاء، هتلاقي **address + port** بتاعك في صفحة السيرفر.

### 4) ارفع الملفات
من **File Manager** أو **SFTP** (بياناته في نفس الصفحة):
ارفع محتويات `nova-24-7/` كلها في مجلد السيرفر (مش المجلد نفسه — **محتوياته**).

### 5) شغّل
في تبويب **Console** أو خانة Startup Command:
```
node server.mjs
```
أو لو لوحتهم بتشغّل `npm start` تلقائي — موجود عندك `package.json` فيه `"start": "node server.mjs"`.

هتشوف في الكونسول:
```
Server listening on 0.0.0.0 (HTTP + /api/ws + /api/local-agent/ws)
Serving static frontend …/public
```

### 6) اتأكد بعينك
افتح في المتصفح:
```
http://<address>:<port>/self-check
```
لازم تشوف حكم أخضر: `البرنامج شغّال ✅`. ولو فيه بند أحمر، جنبه الحل مكتوب.

## عايز HTTPS (عشان تربطه بالصفحة على GitHub Pages)؟

الصفحة على `https` مش بتقدر تكلم `http`. الحل **بدون أي حساب**:

```
sh start-tunnel.sh
```

السكربت بينزّل `cloudflared` ويشغّل تونيل، ويطبّع سطر زي:
```
https://something-random.trycloudflare.com
```
خد الرابط ده → صفحة **نوفا · الأسطول الموحّد** → **«وسّع القدرات»** → الصقه → **«اختبر واربط»**.

> **بصراحة:** رابط التونيل بيتغير كل مرة العملية تتشغّل من جديد (مش بيحصل كتير —
> فيه auto-restart بس لو الكود وقع). لو اتغير، الصق الرابط الجديد في نفس المكان، ثانية واحدة.
